# 👩‍🍳 VM AI Kitchen - Premium AI Recipe Generator

VM AI Kitchen is a smart, interactive culinary assistant built with Python and Streamlit, powered by the lightning-fast **Groq API** (`llama-3.3-70b-versatile`). It transforms available kitchen ingredients or specific dish requests into fully curated recipes instantly. 

Designed with a premium, playful Kawaii theme, the app provides a highly engaging and modern user experience for food enthusiasts.

---

## ✨ Features

- 🎒 **Dual Search Modes:** Generate recipes either by entering leftover ingredients from your fridge or by searching for a specific dish directly.
- 🎛️ **Interactive Portion Scaler:** Dynamically scale ingredient quantities and nutritional value estimations based on the number of servings (from 1 to 8 foodies).
- 🌐 **Multi-Language Support:** Instant recipe generation in English, pure Hindi (Devanagari script), or conversational Roman Urdu/Hinglish.
- 🛒 **Smart Prep Checklist:** Interactive checkboxes to cross off items as you gather them.
- 🎬 **AI Video Guide Integration:** Generates a direct, safe link to step-by-step visual cooking tutorials on YouTube tailored to the specific dish.
- 🕒 **Saved History & Profiles:** Keeps track of your recently searched recipes during the session, allowing you to view them again instantly.

---

## 🛠️ Tech Stack

- **Frontend & UI:** Streamlit (Custom CSS Premium Kawaii Theme)
- **AI Engine:** Groq API (`OpenAI` Python Client Client Wrapper)
- **Language Model:** Llama 3.3 70B Versatile
- **Environment Management:** Python-dotenv
